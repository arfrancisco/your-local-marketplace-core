# Codebase quiz log

Progress tracker for the daily quiz on `docs/codebase-guide.md`.

**Schedule:** weekdays, 9:00 AM Philippine time (01:00 UTC, Mon-Fri).
**Format:** 6 questions, one module in depth, mostly from the guide with
occasional live-code questions.
**Rotation:** modules 1 → 11 in order, then mixed review weighted toward
whatever is marked shaky below.

The quiz session appends one row per session and updates the mastery table.
Nothing here needs to be edited by hand, but feel free to.
